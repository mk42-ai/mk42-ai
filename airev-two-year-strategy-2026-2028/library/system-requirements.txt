ONDEMAND PLATFORM System Requirements · v1.0 02 The sizing decision that comes first OnDemand can run speech-to-text, embeddings and an LLM on the cluster, or use an external AI provider. Decide this first: running them locally roughly quadruples CPU and memory. Local AI/ML disabled Only the application services and data stores run on the cluster. AI calls go to an external API. Smallest footprint; the default choice. Local AI/ML enabled Whisper (speech-to-text), BGE-M3 (embeddings) and a local LLM run as pods. No external dependency.

BGE-M3 (embeddings) and a local LLM run as pods. No external dependency. Pick this for air-gapped sites or data residency requirements.
