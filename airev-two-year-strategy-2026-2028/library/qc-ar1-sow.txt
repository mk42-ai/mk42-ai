Overview
The platform is a single OnDemand agent runtime with two execution planes. Everything the
wearer says is handled on the glasses; everything the wearer wants done in the world can — with
consent — be orchestrated in the cloud from a text-only intent.

4. Edge Engineering Detail
“Your voice never leaves the device.”
STT and TTS execute completely on-edge on the Snapdragon AR1 Hexagon NPU, micro-NPU and
always-on audio path. There is no code path in the OnDemand AR1 runtime that transmits
microphone audio oﬀ the glasses — in either operating mode.
4.1 Speech pipeline on the AR1 audio path
Always-on wake word / low-power voice activation — runs on the AR1 low-power audio
subsystem, aligned with the platform's 'always-on audio' and wake-with- voice capabilities; the
main NPU stays asleep until the wake word is conﬁrmed.

voice capabilities; the
main NPU stays asleep until the wake word is conﬁrmed.
On-device streaming STT — a quantized streaming ASR model on the Hexagon NPU emits partial
transcripts within a few hundred milliseconds, with EN/AR support prioritised for the UAE launch
and additional locales added via OTA model packs.
On-device neural TTS — a compact neural vocoder pipeline renders speech to the custom
speakers with barge-in support so the wearer can interrupt the assistant.

speakers with barge-in support so the wearer can interrupt the assistant.
Audio hygiene — 5-mic beam-forming, echo cancellation for the open-ear speakers and a privacy
LED / HUD indicator whenever the microphones are active.
4.2 On-edge small language models
Two AIREV harness-tr ained SLMs serve local NLU, tool routing and conversational continuity (full
model cards in Section 6).

tool routing and conversational continuity (full
model cards in Section 6). The 0.8B model is the default on AR1 Gen 1-class memory budgets and
the always-res ident router on AR1+; the ~2B Gemma-4-E2B model is loaded on AR1+ for richer
oﬄine reasoning and plugin orchestration when thermal and battery headroom allow. Both emit
strict JSON tool calls, which is what makes a sub-1B model dependable as an on-glass agent.

tool calls, which is what makes a sub-1B model dependable as an on-glass agent.
4.3 Mini-RAG over private memory
A local retrieval layer indexes past interactions, documents, artifacts and explicit memories
(“remember where I parked”) into an on-device vector store. Retrieval happens before every SLM
turn, giving the oﬄine assistant continuity across days without any cloud account. Indexing is
deferred to charging or idle windows to protect battery, and the store lives inside the secure
enclave-backed encrypted partition.

and the store lives inside the secure
enclave-backed encrypted partition.
